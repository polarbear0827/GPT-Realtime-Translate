# Keynote Live Translator v0.5.2

The floating captions window is now responsive and adjustable.

- **Resize it freely** — drag any edge or the corner grip. The text grows and shrinks with the window
  height, and more text fits per line as it gets wider. A− / A+ resize in steps.
- **Background opacity** — from solid frosted glass to fully transparent floating text, right from the
  hover controls. Text shadows strengthen as the background fades so captions stay readable over video.
- **設定 > 懸浮字幕** — opacity, 1–3 translation lines, show or hide the original, lock (click-through),
  and reset position and size.

Install `KeynoteLiveTranslator-0.5.2.pkg` (macOS 12.3 or later; system audio needs macOS 14.2+).
