分享給觀眾

連接分享伺服器

觀眾用手機掃 QR Code 就能看即時翻譯，不用安裝 App。這需要一台你自己的免費分享伺服器（Cloudflare）。

  1. 在這台 Mac 的專案資料夾執行 npm run relay:deploy（第一次會請你登入 Cloudflare）。
  2. 完成後 App 會自動跳出「連接分享伺服器？」，按「連接」就好，不用複製任何東西。

已經部署過了？執行 npm run relay:connect 就能重新連接。

手動輸入網址與發佈金鑰

發佈金鑰只存在這台電腦（macOS 鑰匙圈）。連接後畫面會重新載入一次。

連線中

0位觀眾

暫停中：現在說的話不會送給觀眾，繼續分享後也不會補送。

公告

觀眾畫面

  • 觀眾只能觀看，無法操作任何功能。
  • 開始分享之前的字幕不會送出，暫停期間說的話也不會送出。
  • 觀看人數不影響 OpenAI 的費用。

分享伺服器：

結束後，觀眾畫面會顯示「已結束」，這個 QR Code 也會失效。關閉 App 不會結束分享：12 小時內重新開啟可以接著分享。

設定

直播中無法變更收音與辨識設定，停止後再調整。

收音

選擇「電腦播放的聲音」時會直接擷取 Mac 正在播放的聲音（影片、會議），不需要外放，戴耳機也可以。第一次使用時，macOS 會請你允許「系統錄音」。

辨識

關鍵字與情境說明只用於轉錄模型（gpt-live-transcribe）。

顯示

由 OpenAI 文字模型依語意、語氣判斷一句話在哪裡結束，只決定在哪裡換行，不改動字幕內容。一小時約多花 0.5～1 美元；關閉後改用標點、停頓與連接詞斷句。

懸浮字幕

拖曳懸浮字幕可移動；拖右下角或邊緣可調整大小，字會跟著視窗高度變大變小。滑鼠移到懸浮字幕上也能直接調整大小、透明度、鎖定或關閉。鎖定後可用選單「顯示方式 > 鎖定懸浮字幕」（⌘⇧L）解除。
